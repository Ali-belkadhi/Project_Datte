# SIWAR — Guide Claude

Ce projet est une boutique e-commerce de luxe pour la marque tunisienne SIWAR (Kébili).
- Stack : Next.js App Router, TypeScript, Tailwind CSS, Three.js, GSAP, Zustand.
- Architecture racine : pas de dossier `src/`, tout se trouve directement sous la racine (`app/`, `components/`, etc.).
