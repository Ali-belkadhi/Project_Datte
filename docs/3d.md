# 3D procédurale (module B)

Toute la 3D est **générée en code** avec React Three Fiber + drei : aucun fichier 3D, aucun HDR, aucune requête réseau.

## Organisation (`src/components/three`)

| Dossier | Contenu |
| --- | --- |
| `presets.ts` | Couleur, forme et matériau de chaque variété ; matières (terre cuite, kraft, verre…) ; `shade`, `mulberry32`, `seedFrom`, `dateVariation`. Partagé avec les illustrations SVG. |
| `geometry/` | `createDateGeometry` (LatheGeometry + bruit simplex pour les rides), calice, profils de bocal, bouteille, coupelle. Cache de 4 variantes par forme. |
| `models/` | `DateFruit`, `DatePile`, `DateCluster` (balancement ±1,5°), `GiftBox`, `Jar`, `Bottle`, `Pouch`, étiquettes `CanvasTexture`, `ModelFromSource`. |
| `canvas/` | `SceneCanvas` (dpr [1, 2], ACES Filmic, sRGB, fond transparent), `LightRig` (ambiante, directionnelle chaude, contre-jour ambré, `Environment` + 3 `Lightformer`), `StudioFloor` (disque + `ContactShadows`), `LazyScene`. |
| `scenes/` | `HeroCluster`, `ProductViewer` (OrbitControls, rotation auto stoppée à l'interaction, Recentrer / Plein écran / AR désactivé), `VarietyShowcase`, `StudioPreview` (fil de fer, rotation, fond), `SingleDate`, `DateLineup`, `lazy.tsx`. |

## Chargement

Les pages n'importent que `LazyScene` + `LazyHeroCluster` / `LazyProductViewer` / `LazySingleDate` / `LazyDateLineup` (`next/dynamic`, `ssr: false`). `LazyScene` monte la scène quand elle entre dans le viewport, affiche un squelette, et retombe sur l'illustration SVG si WebGL est indisponible. `prefers-reduced-motion` coupe rotations et balancements.

## Brancher les GLB Meshy

1. La génération Meshy (webhook `api/webhooks/meshy`) copie le GLB/USDZ vers R2 et met à jour `Modele3D.glbUrl`.
2. Le repository Prisma renvoie `modele3D: { kind: "glb", url: glbUrl }` dans le DTO `Produit`.
3. `ModelFromSource` affiche déjà la branche `glb` via `useGLTF` (centré, posé sur le sol) : **aucune page ne change**.
4. Pour l'AR, activer le bouton « Voir chez moi » avec `model-viewer` / Quick Look (USDZ) côté client.

## Performance

`frameloop="demand"` pour les viewers statiques, au plus ~33 dattes dans le hero, géométries et matériaux partagés, `dpr` plafonné à 2.
